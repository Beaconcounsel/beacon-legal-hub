---
name: Bilingual EN/FR i18n system
description: Website uses react-i18next with static JSON translations, /fr/ URL prefix, language toggle in header, hreflang SEO tags
type: feature
---
- i18n config at src/i18n/index.ts, translations at src/i18n/en.json and src/i18n/fr.json
- /fr/ prefix routes defined in App.tsx alongside English routes
- LanguageRouter component detects language from URL path
- LanguageSwitch component in Header toggles EN/FR
- LocalizedLink component auto-prefixes /fr/ for French
- SEOHead component manages hreflang tags and translated meta
- Language preference persisted in localStorage
- Auto-detects browser language on first visit
